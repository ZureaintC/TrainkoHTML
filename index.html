常见问题

如何管理或取消会员订阅？

所有会员订阅均通过 Apple App Store（StoreKit 2）进行扣费与管理。你可以随时在 iOS「系统设置 → 顶部 Apple ID → 订阅 → Trainko」或 App 内会员充值页底部的「管理订阅」中取消或更改方案。如需取消，请在当前周期结束前至少 24 小时操作。

需要注册账号吗？数据保存在哪里？

完全不需要注册账号。Trainko 严格遵循本地优先原则，所有训练记录、健身房配置和个人身体档案均保存在你的 iPhone 本地。开通会员并开启 iCloud 云同步后，数据直接通过苹果私有 CloudKit 数据库跨设备同步，开发者绝无中心化用户服务器。

可以关闭本地 HTTP API 服务吗？

可以。你随时可以在 App「设置 → API 服务」中一键开启或关闭本地 API 服务。关闭后本地 HTTP 服务将彻底停止监听，充分保护隐私与电量。

支持哪些 AI Agent？

任何支持 HTTP 请求的 AI Agent 均可连接，包括桌面端智能体、自定义工作流以及本地运行的脚本。

支持哪些语言？

17 种国际化语言：简体中文、English、繁體中文、日本語、한국어、Español、Français、Deutsch、Italiano、Português (BR)、Русский、العربية、Čeština、Magyar、Polski、Türkçe、Español (LA)。
