隐私政策

最后更新：2026 年 9 月 22 日

一、引言

欢迎使用 Trainko（以下简称"本 App"）。我们非常重视你的隐私和个人信息保护。 本隐私政策旨在向你说明，在你使用本 App 及其提供的本地 HTTP 服务功能时，我们如何收集、使用、存储和保护你的信息。

请你仔细阅读并充分理解本政策。你开始使用本 App，即视为你已阅读并同意本政策的全部内容。 如你对本政策有任何疑问，可联系我们（见本政策第九条）。

二、我们收集的信息

本 App 以"本地优先"为设计原则，你的绝大部分数据仅存储在你的设备上，不会被上传到任何云端服务器。 我们可能处理的个人信息包括：

1. 训练与身体数据

  • 你手动录入或通过 AI Agent 写入的训练计划、训练记录、动作数据；
  • 你的基础身体资料，如体重、身高、性别、出生日期等；
  • 训练过程中记录的时长、组数、次数、重量等过程数据。

2. Apple 健康（HealthKit）数据

在你主动开启"自动同步"并授权后，本 App 会与 Apple 健康应用交互，具体如下：

  • 读取：体重、身高、体脂率、心率、性别、出生日期，用于完善你的训练档案；
  • 写入：体重、活动能量、心率以及训练记录，用于将你的训练成果回写至健康应用。

对健康数据的读取与写入均需你通过系统授权页面主动授权，你可随时在"设置 → 隐私与安全 → 健康"中关闭对本 App 的授权。

三、数据的存储与安全

  • 本地存储：你的训练与身体数据保存在设备本地的 SwiftData 数据库中；部分偏好设置保存在系统 UserDefaults 中。
  • 无云端服务器：本 App 不设置云账号体系，不将你的个人数据上传至任何第三方服务器。
  • API Key：用于本地 HTTP 服务鉴权的 API Key 在你的设备上本地生成并安全保存，仅用于你主动配置的 AI Agent 与本 App 之间的通信。
  • 数据隔离：iCloud 同步功能当前尚未开放，我们不会主动将你的数据同步至 iCloud。

四、本地 HTTP 服务与 API Key

本 App 内置一个仅在本机运行的本地 HTTP 服务，供你自行配置的 AI Agent 通过 API 为你定制训练计划。

  • 该服务默认仅监听本机地址，你需要持有 API Key 才能访问。
  • API Key 仅在你的设备与你的 AI Agent 之间使用，请勿泄露给他人。
  • 如担心 Key 泄露，可随时在"设置"中重新生成，旧 Key 将立即失效。

五、第三方数据访问

除 Apple 健康（HealthKit）外，本 App 不接入其他第三方 SDK，也不会将你的数据提供给任何第三方用于广告、画像或其他商业目的。

六、数据的删除

  • 你可在"设置 → 数据管理 → 清除所有数据"中删除本 App 保存的全部训练记录与个人资料。
  • 卸载本 App 会一并删除其保存在设备上的数据（Apple 健康中的历史记录不受影响）。
  • 如需撤回 Apple 健康授权，请在系统"设置 → 隐私与安全 → 健康"中进行操作。

七、未成年人保护

本 App 面向一般成年人健身场景。若你为未满 18 周岁的未成年人，请在监护人的指导下使用本 App， 并确保已征得监护人同意。

八、本政策的变更

我们可能根据法律法规或产品功能的变化适时更新本政策。更新后的政策将在本 App 内公示，并自公示之日起生效。 建议你定期查阅，以了解最新内容。
